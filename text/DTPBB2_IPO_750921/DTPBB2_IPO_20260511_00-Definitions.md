# คำจำกัดความ

| “กฎหมายหลักทรัพย์” | พระราชบัญญัติหลักทรัพย์และตลาดหลักทรัพย์ พ.ศ. 2535 พระราชบัญญัติทรัสต์เพื่อธุรกรรมในตลาดทุน พ.ศ. 2550 ประกาศคณะกรรมการกำกับหลักทรัพย์และตลาดหลักทรัพย์ ประกาศคณะกรรมการกำกับตลาดทุน ประกาศสำนักงานคณะกรรมการกำกับหลักทรัพย์และตลาดหลักทรัพย์ รวมถึงหนังสือเวียน หนังสือผ่อนผัน หนังสือซักซ้อมความเข้าใจ หนังสืออนุญาต กฎ ระเบียบ ข้อบังคับ  <br> และ/หรือ เอกสารอื่นใดที่มีผลใช้บังคับตามกฎหมายที่ออกโดยอาศัยอำนาจตามพระราชบัญญัติหลักทรัพย์และตลาดหลักทรัพย์ พ.ศ. 2535 และ/หรือ พระราชบัญญัติทรัสต์เพื่อธุรกรรมในตลาดทุน พ.ศ. 2550 และ/หรือ กฎหมายอื่นใดที่เกี่ยวข้อง ทั้งที่มีอยู่ในปัจจุบัน และที่ได้มีการแก้ไขเพิ่มเติม |

| “กองทรัสต์” | ทรัสต์เพื่อการลงทุนในกรรมสิทธิ์อสังหาริมทรัพย์ ดีทีพี ออฟฟิศ  <br> ที่มีข้อตกลงในการซื้อคืน |
| “กองทรัสต์ DTPBB” | ทรัสต์เพื่อการลงทุนในสิทธิการเช่าอสังหาริมทรัพย์ ดีทีพี โฮเทล และเซอร์วิส อพาร์ทเมนท์ ที่มีเงื่อนไขและเวลาบอกเลิกสัญญาเช่า |
| “กลุ่มบุคคลเดียวกัน” | บุคคลที่มีความสัมพันธ์ในลักษณะใดลักษณะหนึ่งหรือหลายลักษณะดังต่อไปนี้ ตามประกาศที่ ทจ. 49/2555 <br> (1) คู่สมรสและบุตรที่ยังไม่บรรลุนิติภาวะ <br> (2) นิติบุคคล และผู้ถือหุ้นหรือผู้เป็นหุ้นส่วนของนิติบุคคลนั้นซึ่งถือหุ้น หรือเป็นหุ้นส่วนในนิติบุคคลดังกล่าวไม่ว่าทางตรงหรือทางอ้อมเกินกว่าร้อยละห้าสิบของจำนวนหุ้นที่จำหน่ายได้แล้วทั้งหมดหรือความเป็นหุ้นส่วนทั้งหมด <br> (3) กองทุนส่วนบุคคลของบุคคลตาม (1) หรือ (2) แต่ทั้งนี้ มิให้รวมถึงกองทุนสำรองเลี้ยงชีพ |
| “การจัดหาผลประโยชน์จากทรัพย์สินหลัก” | การให้เช่าอสังหาริมทรัพย์และสังหาริมทรัพย์แก่ผู้ประกอบธุรกิจให้เช่า/บริการพื้นที่สำนักงาน และ/หรือ ธุรกิจที่เกี่ยวเนื่องกับธุรกิจให้เช่า/บริการพื้นที่สำนักงาน โดยในเบื้องต้น กองทรัสต์จะให้เช่าอสังหาริมทรัพย์และสังหาริมทรัพย์ที่เป็นทรัพย์สินที่กองทรัสต์จะเข้าลงทุนแก่ DTGO หรือบุคคลอื่นที่เป็นผู้เช่าทรัพย์สินหลักจากกองทรัสต์แทน DTGO |
| “การประเมินค่า” | การคำนวณมูลค่าอสังหาริมทรัพย์ของกองทรัสต์เพื่อวัตถุประสงค์สาธารณะในการเปิดเผยข้อมูลต่อประชาชน โดยเป็นการประเมินอย่างเต็มรูปแบบ ซึ่งต้องมีการตรวจสอบเอกสารสิทธิ ข้อจำกัดสิทธิครอบครองในทรัพย์สิน เงื่อนไขและข้อจำกัดทางกฎหมาย ข้อจำกัดอื่นของการใช้ประโยชน์ รายละเอียดการใช้ประโยชน์ในปัจจุบัน และรายละเอียดอื่นที่เกี่ยวข้องรวมทั้งการสำรวจทรัพย์สินตามสภาพที่เป็นอยู่ |
| “การบริหารอสังหาริมทรัพย์” | การดูแลรักษาให้อสังหาริมทรัพย์ของกองทรัสต์อยู่ในสภาพที่ดีและพร้อมที่จะใช้ในการจัดหาผลประโยชน์ได้ตลอดเวลา ตลอดจนการจัดหาผลประโยชน์จากอสังหาริมทรัพย์ดังกล่าวด้วยตามที่ประกาศคณะกรรมการกำกับหลักทรัพย์และตลาดหลักทรัพย์กำหนด รวมทั้งการบริหารอสังหาริมทรัพย์ตามที่กฎหมายหลักทรัพย์ และ/หรือ กฎหมายอื่นใดที่เกี่ยวข้องกำหนด |
| “การสอบทานการประเมินค่า” | การเสนอความเห็นเกี่ยวกับมูลค่าอสังหาริมทรัพย์ของกองทรัสต์ โดยมิได้มีการสำรวจทรัพย์สิน |
| “คณะกรรมการ ก.ล.ต.” | คณะกรรมการกำกับหลักทรัพย์และตลาดหลักทรัพย์ตามกฎหมายว่าด้วยหลักทรัพย์และตลาดหลักทรัพย์ ซึ่งรวมถึงคณะกรรมการกำกับตลาดทุน |
| “โครงการสำนักงานดีทีจีโอ แคมป์อัส” | โครงการสำนักงานดีทีจีโอ แคมป์อัส หรือชื่อภาษาอังกฤษ DTGO CAMPUS ตั้งอยู่เลขที่ 695 และ 695/1 หมู่ที่ 12 ตำบลบางแก้ว อำเภอบางพลี จังหวัดสมุทรปราการ |
| “เจ้าของเดิม” | บุคคลที่เป็นเจ้าของและเป็นผู้ขายอสังหาริมทรัพย์ที่กองทรัสต์จะลงทุนให้แก่กองทรัสต์ ซึ่งรวมถึงกลุ่มบุคคลเดียวกันของบุคคลดังกล่าว |
| “ดีทีจีโอ” หรือ “DTGO” | บริษัท ดีทีจีโอ คอร์ปอเรชั่น จำกัด |
| “ตลาดหลักทรัพย์” | ตลาดหลักทรัพย์แห่งประเทศไทย |
| “ที่ปรึกษาทางการเงิน” | บริษัท ดิสคัฟเวอร์ แมเนจเม้นท์ จำกัด ในฐานะที่ปรึกษาทางการเงินที่อยู่ในรายชื่อบริษัทที่เป็นที่ปรึกษาทางการเงิน ที่ได้รับความเห็นชอบจากสำนักงาน ก.ล.ต. |
| “ทรัพย์สินหลัก” หรือ “ทรัพย์สินที่กองทรัสต์จะเข้าลงทุน” | ทรัพย์สินที่กองทรัสต์สามารถลงทุนได้ตามหลักเกณฑ์ที่กำหนดในประกาศที่ ทจ. 49/2555 โดยในการเข้าลงทุนในทรัพย์สินหลักของกองทรัสต์ ในครั้งนี้ กองทรัสต์จะเข้าลงทุนในโครงการสำนักงานดีทีจีโอ แคมป์อัส ซึ่งประกอบไปด้วย <br> กรรมสิทธิ์ที่ดินซึ่งเป็นที่ตั้งของโครงการสำนักงานดีทีจีโอ แคมป์อัส <br> กรรมสิทธิ์อาคารที่ใช้สำหรับประกอบกิจการโครงการสำนักงาน <br> ดีทีจีโอ แคมป์อัส ซึ่งรวมถึงแต่ไม่จำกัดเพียงอาคารสำนักงาน <br> กรรมสิทธิ์สังหาริมทรัพย์ที่ใช้ในการประกอบกิจการโครงการสำนักงานดีทีจีโอ แคมป์อัส ซึ่งรวมถึงแต่ไม่จำกัดเพียง เฟอร์นิเจอร์ เครื่องมือ เครื่องใช้ อุปกรณ์ตกแต่งที่ติดตรึงตราและไม่ติดตรึงตรา |

| “แบบแสดงรายการข้อมูลประจำปีของกองทรัสต์” | แบบแสดงรายการข้อมูลประจำปีของกองทรัสต์ (แบบ 56-REIT1) |

| “บริษัทประเมินค่าทรัพย์สิน” หรือ “ผู้ประเมินมูลค่าทรัพย์สิน” | บริษัทประเมินมูลค่าทรัพย์สินของกองทรัสต์ที่ได้รับการแต่งตั้งจากผู้จัดการกองทรัสต์และได้รับความเห็นชอบจากสำนักงาน ก.ล.ต. |

| “ประกาศที่ ทจ. 49/2555” | ประกาศคณะกรรมการกำกับตลาดทุน ที่ ทจ. 49/2555 เรื่องการออกและเสนอขายหน่วยทรัสต์ของทรัสต์เพื่อการลงทุนในอสังหาริมทรัพย์  <br> ลงวันที่ 21 พฤศจิกายน 2555 และที่ได้มีการแก้ไขเพิ่มเติม |

| “ประกาศที่ สช. 29/2555” | ประกาศสำนักงานคณะกรรมการกำกับหลักทรัพย์และตลาดหลักทรัพย์ ที่ สช. 29/2555 เรื่อง หลักเกณฑ์ เงื่อนไข และวิธีการในการให้ความเห็นชอบผู้จัดการกองทรัสต์ และมาตรฐานการปฏิบัติงาน ลงวันที่  <br> 21 พฤศจิกายน 2555 และที่ได้มีการแก้ไขเพิ่มเติม |

| “ผู้ลงทุนสถาบัน” | ผู้ลงทุนสถาบันตามประกาศคณะกรรมการกำกับหลักทรัพย์และตลาดหลักทรัพย์ว่าด้วยการกำหนดบทนิยามผู้ลงทุนสถาบัน ผู้ลงทุนรายใหญ่พิเศษ และผู้ลงทุนรายใหญ่ |
| “ผู้ลงทุนรายใหญ่พิเศษ” | ผู้ลงทุนรายใหญ่พิเศษตามประกาศคณะกรรมการกำกับหลักทรัพย์และตลาดหลักทรัพย์ว่าด้วยการกำหนดบทนิยามผู้ลงทุนสถาบัน ผู้ลงทุนรายใหญ่พิเศษ และผู้ลงทุนรายใหญ่ |
| “ผู้สอบบัญชี” | ผู้สอบบัญชีของกองทรัสต์ ซึ่งเป็นผู้สอบบัญชีที่อยู่ในบัญชีรายชื่อที่ได้รับความเห็นชอบจากสำนักงาน ก.ล.ต. ตามประกาศสำนักงาน ก.ล.ต.  <br> ว่าด้วยการให้ความเห็นชอบผู้สอบบัญชีในตลาดทุน และที่ได้มีการแก้ไขเพิ่มเติม |
| “ผู้เสนอขายหน่วยทรัสต์” | ผู้ก่อตั้งทรัสต์ ซึ่งจะเข้าเป็นผู้จัดการกองทรัสต์เมื่อมีการก่อตั้งกองทรัสต์แล้วเสร็จ |
| “พ.ร.บ. ทรัสต์” หรือ “พ.ร.บ. ทรัสต์ฯ”  <br> หรือ “พระราชบัญญัติทรัสต์” | พระราชบัญญัติทรัสต์เพื่อธุรกรรมในตลาดทุน พ.ศ. 2550 และที่ได้มีการแก้ไขเพิ่มเติม |
| “พ.ร.บ. หลักทรัพย์” หรือ “พ.ร.บ. หลักทรัพย์ฯ” | พระราชบัญญัติหลักทรัพย์และตลาดหลักทรัพย์ พ.ศ. 2535 และที่ได้มีการแก้ไขเพิ่มเติม |
| “เอ็มทีอาร์เอ” หรือ “MTRA” | บริษัท เอ็มคิวดีซี ทาวน์ รอยัล แอสเซท จำกัด |
| “รายงานการประเมินค่า” | รายงานการประเมินมูลค่าทรัพย์สินที่กองทรัสต์จะลงทุน ซึ่งจัดทำขึ้นตามหลักเกณฑ์ในประกาศที่ ทจ. 49/2555 |
| “รอบปีบัญชี” | ระยะเวลาตั้งแต่วันที่ 1 กรกฎาคม ถึง วันที่ 30 มิถุนายน |
| “วันทำการ” | วันที่ผู้จัดการกองทรัสต์เปิดทำการ (ซึ่งไม่ใช่วันเสาร์ วันอาทิตย์ วันหยุดราชการ หรือวันที่สำนักงาน ก.ล.ต. ประกาศให้เป็นวันหยุด) |
| “สัญญาก่อตั้งทรัสต์” | สัญญาก่อตั้งทรัสต์ ระหว่างผู้ก่อตั้งทรัสต์ (ซึ่งจะเข้าเป็นผู้จัดการกองทรัสต์เมื่อมีการก่อตั้งกองทรัสต์แล้ว) กับทรัสตี |
| “สัญญาลงทุน” หรือ “สัญญาเข้าลงทุน” | สัญญาดังต่อไปนี้ ซึ่งกองทรัสต์จะเข้าทำเพื่อการลงทุนในทรัพย์สินหลัก <br> สัญญาขายฝากอสังหาริมทรัพย์ โครงการสำนักงานดีทีจีโอ แคมป์อัส ระหว่าง กองทรัสต์โดยทรัสตี กับ MTRA (“สัญญาขายฝากอสังหาริมทรัพย์”) และ/หรือ <br> สัญญาซื้อขายสังหาริมทรัพย์ โครงการสำนักงานดีทีจีโอ  <br> แคมป์อัส ระหว่าง กองทรัสต์โดยทรัสตี กับ MTRA (“สัญญาซื้อขายสังหาริมทรัพย์”) และ/หรือ <br> สัญญาจะซื้อจะขายทรัพย์สินคืน โครงการสำนักงานดีทีจีโอ แคมป์อัส ระหว่าง กองทรัสต์โดยทรัสตี กับ MTRA (“สัญญาจะซื้อจะขายทรัพย์สินคืน”) และ/หรือ <br> สัญญาตกลงกระทำการ โครงการสำนักงานดีทีจีโอ แคมป์อัส ระหว่าง กองทรัสต์โดยทรัสตี กับ DTGO (“สัญญาตกลง <br> กระทำการ (DTGO)”) <br> สัญญาตกลงกระทำการ โครงการสำนักงานดีทีจีโอ แคมป์อัส ระหว่าง กองทรัสต์โดยทรัสตี กับ MQDC (“สัญญาตกลง <br> กระทำการ (MQDC)”) |
| “สัญญาจัดหาประโยชน์” | สัญญาเช่าทรัพย์สิน โครงการสำนักงานดีทีจีโอ แคมป์อัส ระหว่างกองทรัสต์โดยทรัสตี กับ DTGO ซึ่งกองทรัสต์จะเข้าทำเพื่อการจัดหาผลประโยชน์จากทรัพย์สินหลัก |
| “สัญญาแต่งตั้งผู้จัดการกองทรัสต์” | สัญญาแต่งตั้งผู้จัดการกองทรัสต์ ระหว่างทรัสตีกับผู้จัดการกองทรัสต์ |
| “สำนักงาน ก.ล.ต.” หรือ “สำนักงานฯ” | สำนักงานคณะกรรมการกำกับหลักทรัพย์และตลาดหลักทรัพย์ |
| “หนังสือรับรองจากทรัสตี” | หนังสือรับรองจากทรัสตีหรือผู้ที่จะเข้าเป็นทรัสตีของกองทรัสต์ว่าจะยอมรับที่จะเข้าปฏิบัติหน้าที่เป็นทรัสตีของกองทรัสต์ ตามหลักเกณฑ์ที่กำหนดไว้ในประกาศที่ ทจ. 49/2555 และประกาศอื่นใดที่เกี่ยวข้องที่ออกตาม พ.ร.บ. ทรัสต์ฯ |
| “หน่วยทรัสต์” | ใบทรัสต์ที่แสดงสิทธิของผู้ถือในฐานะผู้รับประโยชน์ในกองทรัสต์ |
| “เหตุสุดวิสัย” | เหตุใด ๆ ที่เกิดขึ้นหรือก่อให้เกิดผลพิบัติซึ่งไม่อาจป้องกันได้ ถึงแม้ว่าบุคคลที่ประสบหรือใกล้จะประสบเหตุนั้นจะได้ใช้ความระมัดระวังตามสมควรดังเช่นบุคคลทั่วไปจะทำได้ในฐานะและภาวะเช่นนั้น เช่น  <br> ภัยธรรมชาติ อัคคีภัย น้ำท่วม แผ่นดินไหว อุบัติเหตุที่ไม่สามารถหลีกเลี่ยงได้ สงคราม จลาจล การก่อการร้าย การนัดหยุดงาน การปิดสถานที่ทำงาน โรคระบาด เป็นต้น และหมายความรวมถึงการบัญญัติกฎหมายหรือกฎเกณฑ์หรือการดำเนินการอื่นใดของรัฐ หรือข้อจำกัดทางกฎหมายหรือกฎเกณฑ์ซึ่งมีผลกระทบต่อการปฏิบัติตามสัญญา หรือสาเหตุใด ๆ ที่มีผลทำนองเดียวกันซึ่งคู่สัญญาที่ได้รับผลกระทบไม่อาจควบคุมได้ <br> ทั้งนี้ ในกรณีที่เกี่ยวข้องกับการชำระเงินหรือธุรกรรมใดในการปฏิบัติตามสัญญาอันจะต้องดำเนินการกับธนาคารพาณิชย์ เหตุสุดวิสัยให้หมายความรวมถึงการที่ธนาคารพาณิชย์ในประเทศไทยทุกธนาคารหยุดทำการด้วย |
