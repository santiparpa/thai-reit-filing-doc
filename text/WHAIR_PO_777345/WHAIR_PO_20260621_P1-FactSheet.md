| สมมติฐานสำคัญในการคำนวณ IRR ; กระแสเงินสดจากทรัพย์สินหลักที่จะลงทุนเพิ่มเติมครั้งที่หก คำนวณจากรายงานประเมินของผู้ประเมินอิสระ ฉบับลงวันที่ / 7 พฤษภาคม 2569 ; ค่าใช้จ่ายระดับกองทรัสต์ตามสัญญา/3 / ไม่เกินร้อยละ 2.00 ของ NAV ; สัดส่วนการกู้ยืมในทรัพย์สินหลักที่ลงทุนเพิ่มเติมครั้งที่หก / ประมาณร้อยละ 28.35 <br> ของสินทรัพย์รวม ; สมมติฐานอัตราดอกเบี้ยเงินกู้ / ไม่เกินอัตรา MLR ลบร้อยละ1.50 ต่อปี | Expected IRR/2 ; กรณีมีรายได้ตามสัญญาตกลงกระทำการ / ร้อยละ 10.71 ; กรณีไม่มีรายได้ตามสัญญาตกลงกระทำการ / ร้อยละ 10.67 |

(3)	มีการจัดสรรหน่วยทรัสต์ให้แก่บุคคลใด กลุ่มบุคคลเดียวกันใด ผู้ก่อตั้งทรัสต์ ทรัสตี ผู้จัดการกองทรัสต์ หรือผู้ลงทุนต่างด้าว ไม่เป็นไปตามอัตราหรือหลักเกณฑ์ที่กำหนด และไม่สามารถแก้ไขให้ถูกต้อง
(4)	เมื่อเกิดเหตุสุดวิสัย การเปลี่ยนแปลงอย่างมีนัยสำคัญทางด้านกฎหมาย การเงิน เศรษฐกิจ ภาวะตลาดหลักทรัพย์ หรือการเมืองทั้งในประเทศและต่างประเทศ หรือการเปลี่ยนแปลงอย่างมีนัยสำคัญที่มีผลกระทบต่อทรัพย์สินที่กองทรัสต์จะเข้าลงทุน
(5)	เมื่อมีเหตุที่ทำให้สำนักงาน ก.ล.ต. หรือหน่วยงานราชการ สั่งระงับหรือหยุดการเสนอขายหลักทรัพย์ หรือไม่สามารถส่งมอบหลักทรัพย์ที่เสนอขายได้
(6)	มีเหตุอื่นใดตามเงื่อนไขการบอกเลิกสัญญาที่กำหนดไว้ในสัญญาแต่งตั้งผู้จัดการการจัดจำหน่าย (Underwriting Agreement)
