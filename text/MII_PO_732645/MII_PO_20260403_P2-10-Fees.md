## ค่าธรรมเนียมและค่าใช้จ่ายทั้งหมดที่เรียกเก็บจากกองทรัสต์

| ค่าธรรมเนียมและค่าใช้จ่ายของกองทรัสต์ | เพดานสูงสุดต่อปี หรือภายหลังการทำธุรกรรมในแต่ละครั้ง <br> (ไม่รวมภาษีมูลค่าเพิ่ม) | รอบและระยะเวลาที่เรียกเก็บ |
|---|---|---|
| ค่าธรรมเนียมผู้จัดการกองทรัสต์ | ค่าธรรมเนียมพื้นฐาน: ไม่เกินร้อยละ 1.00 (หนึ่ง) ต่อปีของมูลค่าทรัพย์สินรวมของกองทรัสต์ | รายเดือน |
|  | ค่าธรรมเนียมการได้มา และจำหน่ายไปซึ่งทรัพย์สินหลักและสังหาริมทรัพย์ที่เกี่ยวข้องกับทรัพย์สินหลักของกองทรัสต์: ไม่เกินร้อยละ 1.00 (หนึ่ง) ของมูลค่าทรัพย์สินหลักและสังหาริมทรัพย์ที่เกี่ยวข้องกับทรัพย์สินหลักที่ได้มาหรือจำหน่ายไป | เมื่อเกิดรายการ |
| ค่าธรรมเนียมทรัสตีและผู้เก็บรักษาทรัพย์สิน | ไม่เกินร้อยละ 0.50 (ศูนย์จุดห้าศูนย์) ต่อปี ของมูลค่าทรัพย์สินรวมของกองทรัสต์ <br> ทั้งนี้ ไม่ต่ำกว่า 2,000,000 (สองล้าน) บาทต่อปี <br> โดยไม่รวมค่าธรรมเนียมการจัดการกองทุนรวมหรือค่าธรรมเนียมตราสารอื่นใดที่กองทรัสต์ สามารถเข้าลงทุนและได้พิจารณาเข้าลงทุน เนื่องจากการรับหน้าที่เป็นผู้จัดการกองทุนรวมหรือผู้ออกตราสารดังกล่าวโดยทรัสตี | รายเดือน |
| ค่าธรรมเนียมการบริหารอสังหาริมทรัพย์ | ตามอัตราที่ระบุในสัญญาแต่งตั้งผู้บริหารอสังหาริมทรัพย์ ทั้งนี้ ไม่เกินอัตราร้อยละ 3 ต่อปี ของมูลค่าทรัพย์สินสุทธิ <br> ทั้งนี้ ไม่รวมค่าธรรมเนียมผู้แทน ตัวแทน ค่านายหน้า ซึ่งรวมถึงค่าธรรมเนียมในการจัดหาผู้เช่า หรือต่อสัญญาเช่า (Commission Fee) | รายเดือน |
| ค่าธรรมเนียมผู้แทน ตัวแทน ค่านายหน้า (agent or property broker fee) (ถ้ามี) ที่ทำหน้าที่ทางการตลาด เช่น ดำเนินการซื้อ ขาย หรือโอนสิทธิซึ่งอสังหาริมทรัพย์ หรือสิทธิการเช่าอสังหาริมทรัพย์ เช่า หรือดำเนินการด้านการตลาด รวมถึง ค่าธรรมเนียมในการจัดหาผู้เช่า หรือต่อสัญญาเช่า (commission fee) | ตามที่จ่ายจริง | เมื่อเกิดรายการ |
| ค่าธรรมเนียมนายทะเบียนและค่าใช้จ่ายที่เกี่ยวข้องกับการจัดทำทะเบียน | ตามที่จ่ายจริง | รายเดือน |
| ค่าธรรมเนียมที่ปรึกษาทางการเงิน | ตามที่จ่ายจริง | เมื่อเกิดรายการ |
| ค่าธรรมเนียมและค่าใช้จ่ายในการสอบบัญชี และ/หรือ การตรวจสอบภายใน | ตามที่จ่ายจริง | เมื่อเกิดรายการ |
| ค่าธรรมเนียมที่ปรึกษาอื่น ๆ เช่น ค่าที่ปรึกษากฎหมาย ค่าที่ปรึกษาภาษีอากร | ตามที่จ่ายจริง | เมื่อเกิดรายการ |
| ค่าธรรมเนียมที่ปรึกษา/ผู้เชี่ยวชาญ ที่เกี่ยวข้องกับการจัดการกองทรัสต์ และบริหารทรัพย์สินของกองทรัสต์ ทั้งกรณีที่มีการซื้อ ขาย โอน หรือกรณีใด ๆ เช่น ค่าที่ปรึกษาเฉพาะด้าน ค่าทนายความ ค่าจ้างสำรวจภาพรวมตลาด และ/หรือ ภาวะอุตสาหกรรม ค่าจ้างประเมินระบบวิศวกรรม และ/หรือโครงสร้างอาคาร ค่าที่ปรึกษาผู้คุมงานก่อสร้าง ค่าจ้างวิศวกร <br> คุมงานก่อสร้าง และ/หรือ ประเมินคุณภาพงาน ค่าจ้างตรวจสอบทรัพย์สินจากผู้เชี่ยวชาญ เช่น การตรวจสอบข้อเท็จจริงด้านภาษี และ/หรือ ด้านการเงิน เป็นต้น | ตามที่จ่ายจริง | เมื่อเกิดรายการ |
| ค่าธรรมเนียมในการจัดจำหน่ายและ <br> ค่านายหน้าในการจัดจำหน่ายหน่วยทรัสต์ | ไม่เกินร้อยละ 3.00 (สาม) ของ มูลค่าทรัพย์สินสุทธิของกองทรัสต์ภายหลังการทำธุรกรรมในแต่ละครั้ง | กรณีการจัดตั้งกองทรัสต์ หรือการเพิ่มทุน |
| ค่าธรรมเนียมหรือค่าใช้จ่ายเพื่อการจัดหา ได้มา จำหน่าย จ่าย หรือโอนสินทรัพย์ ทรัพย์สิน หรือหลักทรัพย์ของกองทรัสต์ เช่น ค่าใช้จ่ายในการจำหน่ายหรือโอนสิทธิ ค่าธรรมเนียมการโอน และค่าใช้จ่ายอื่น ๆ ที่เกี่ยวเนื่องกับการเพิ่มทุน หรือได้มาซึ่งทรัพย์สิน | ตามที่จ่ายจริง | เมื่อเกิดรายการ |
| ค่าธรรมเนียม/ค่าใช้จ่ายในการวิเคราะห์และศึกษาความเป็นไปได้และความเหมาะสมในการซื้อ เช่า หรือจำหน่ายอสังหาริมทรัพย์ โอนหรือรับโอนสิทธิการเช่าอสังหาริมทรัพย์ ซึ่งต้องการความเห็นและการศึกษาเพิ่มเติมจากผู้เชี่ยวชาญ | ตามที่จ่ายจริง | เมื่อเกิดรายการ |
| ค่าใช้จ่ายในการโฆษณา ประชาสัมพันธ์ และค่าส่งเสริมการขาย และค่าใช้จ่าย <br> อื่น ๆ ที่เกี่ยวข้องกับการเสนอขายหน่วยทรัสต์ หรือการออกตราสารหนี้เพิ่มเติม หรือกรณีการประชาสัมพันธ์เพื่อให้ข้อมูลแก่นักลงทุน อาทิ ค่าใช้จ่ายในการจัดประชุมนักลงทุนเพื่อนำเสนอขายหน่วยทรัสต์ ค่าเอกสารนำเสนอผู้ลงทุนและผู้ถือหน่วยทรัสต์ | ตามที่จ่ายจริง | เมื่อเกิดรายการ |
| ค่าใช้จ่ายอื่น ๆ |  |  |
| ค่าใช้จ่ายหรือค่าธรรมเนียมที่เกี่ยวข้องในการก่อตั้งกองทรัสต์ และการเพิ่มทุน เช่น ค่าธรรมเนียมการ <br> จดทะเบียนหน่วยทรัสต์ของกองทรัสต์เป็นหลักทรัพย์จดทะเบียน ค่าธรรมเนียมยื่นแบบ Filing ค่าใช้จ่ายในการจัดทำและจัดพิมพ์แบบแสดงรายการข้อมูลการเสนอขายหน่วยทรัสต์ หนังสือชี้ชวน และค่าใช้จ่ายในการจัดเตรียมและจัดทำเอกสาร และค่าแปลเอกสาร | ตามที่จ่ายจริง | เมื่อเกิดรายการ |
| ค่าธรรมเนียมวิชาชีพผู้สอบบัญชีต่อการตรวจสอบประมาณการงบกำไรขาดทุน ค่าใช้จ่ายจัดทำรายงาน หรือบทวิจัย | ตามที่จ่ายจริง | เมื่อเกิดรายการ |
| ค่าใช้จ่ายในการรับชำระเงินค่าซื้อหน่วยทรัสต์ เช่น ค่าธรรมเนียมธนาคาร ค่าอากรแสตมป์  <br> ค่าไปรษณียากร ค่าโทรศัพท์ และ <br> ค่าโทรสาร เป็นต้น | ตามที่จ่ายจริง | เมื่อเกิดรายการ |
| ค่าจัดทำ จัดพิมพ์ ใบจองซื้อหน่วยทรัสต์ ใบหน่วยทรัสต์ ใบเสร็จรับเงิน ใบกำกับภาษี และแบบฟอร์มอื่น ๆ ที่เกี่ยวข้องกับกองทรัสต์ ค่าเอกสารลงบัญชีของกองทรัสต์ และค่าใช้จ่ายในการจัดเตรียมและจัดส่งเอกสารดังกล่าวให้แก่ผู้ถือหน่วยทรัสต์ | ตามที่จ่ายจริง | เมื่อเกิดรายการ |
| ค่าธรรมเนียม และ/หรือ ค่าใช้จ่ายในการประเมินค่า และ/หรือ สอบทานการประเมินค่าทรัพย์สิน และ/หรือการประเมินมูลค่าหุ้น | ตามที่จ่ายจริง | เมื่อเกิดรายการ |
| ค่าธรรมเนียมรายปีและค่าใช้จ่ายในการดำรงสถานะเป็นหลักทรัพย์ <br> จดทะเบียนในตลาดหลักทรัพย์ | ตามที่จ่ายจริง | รายปี |
| ค่าธรรมเนียมและค่าใช้จ่ายในการสอบบัญชีและตรวจสอบภายใน ตลอดจนค่าใช้จ่ายเกี่ยวกับงานบัญชีอื่นของกองทรัสต์ | ตามที่จ่ายจริง | เมื่อเกิดรายการ |
| ภาษี หรือค่าธรรมเนียม และอากรแสตมป์ใด ๆ ที่เกี่ยวกับการซื้อขายหลักทรัพย์ หรืออสังหาริมทรัพย์ เช่น ค่านายหน้าซื้อขายหลักทรัพย์ ซึ่งจะรวมอยู่ในต้นทุนของค่าซื้อขายหลักทรัพย์เมื่อมีการซื้อหลักทรัพย์ และจะถูกหักจากค่าขายหลักทรัพย์เมื่อมีการขายหลักทรัพย์ ค่าใช้จ่ายที่เกี่ยวข้องกับการซื้อหรือขายอสังหาริมทรัพย์ และค่าใช้จ่ายในการโอนหลักทรัพย์ หรืออสังหาริมทรัพย์ เป็นต้น | ตามที่จ่ายจริง | เมื่อเกิดรายการ |
| ค่าใช้จ่ายอื่นใดที่เกี่ยวข้องกับการจัดการกองทรัสต์และการบริหารอสังหาริมทรัพย์และทรัพย์สินที่เกี่ยวข้อง เช่น ค่าใช้จ่ายทางการตลาด รวมถึงค่าโฆษณาประชาสัมพันธ์ ค่าใช้จ่ายในการจัดทำเว็บไซต์ การส่งเสริมการขาย ค่าสาธารณูปโภค ค่าธรรมเนียมธนาคาร ค่าน้ำมัน  <br> ค่าเดินทาง ค่าส่วนกลาง ค่าจัดจ้างพนักงานรักษาความปลอดภัย ค่าใช้จ่ายที่เกี่ยวข้องกับการติดต่อหน่วยงานราชการ เป็นต้น | ตามที่จ่ายจริง | เมื่อเกิดรายการ |
| ค่าใช้จ่ายในการจัดทำประกันภัย ดูแล และ/หรือ เก็บรักษาทรัพย์สินของกองทรัสต์ เช่น ค่าเบี้ยประกันภัยวินาศภัย ค่าเบี้ยประกันอื่นใดที่เกี่ยวเนื่องกับกองทรัสต์และค่าใช้จ่ายต่าง ๆ ในการประกันภัย เป็นต้น | ตามที่จ่ายจริง | เมื่อเกิดรายการ |
| ค่าเช่า และ/หรือเช่าช่วง ที่ดิน อสังหาริมทรัพย์ และ/หรือ สังหาริมทรัพย์ | ตามที่จ่ายจริง | เมื่อเกิดรายการ |
